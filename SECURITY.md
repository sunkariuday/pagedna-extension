# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through the maintainer contact available on the repository owner's GitHub profile. Do not include passwords, cookies, tokens, form values, or other sensitive data in a public issue.

Include a concise description, affected version, reproduction steps using synthetic data, and the potential impact. We will acknowledge reports when possible and coordinate a fix and disclosure timeline based on severity.
