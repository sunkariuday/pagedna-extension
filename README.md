# PageDNA

PageDNA is a Manifest V3 Chrome extension that monitors trusted pages using semantic fingerprints instead of raw HTML hashes. It detects changes to executable code, iframe origins, form destinations, sensitive fields, and navigation boundaries, while masking volatile query parameters and never storing user-entered values.

## Why semantic fingerprints

Hashing raw HTML flags harmless changes (ads, timestamps, A/B tests) as constantly as real ones. PageDNA instead fingerprints the security-relevant structure of a page — script origins, iframe origins, form destinations, sensitive fields, and navigation targets — and masks known-volatile noise such as cache-busting query parameters and autogenerated IDs.

## Features

- Deterministic, bounded 0–100 risk score backed by named, explainable rules
- Evidence for every alert: what changed, the old value, the new value, and why it matters
- Versioned baselines that are never silently overwritten
- Explicit **Trust this change**, **Ignore once**, and **Investigate** decisions
- History timeline of scans and decisions
- Local fixture lab for testing detection without touching a real site
- No passwords, cookies, tokens, or form values are ever stored

## Risk scoring

```
score = min(100,
  boundary_change        * 25 +
  sensitive_flow_change  * 40 +
  new_script_origin      * 15 +
  new_frame_origin       * 10 +
  redirect_change        * 20 +
  unfamiliarity          * 10 +
  compound_bonus         * 40
)
```

| Score | Level |
|---|---|
| 0–19 | LOW |
| 20–49 | MEDIUM |
| 50–79 | HIGH |
| 80–100 | CRITICAL |

## Load in Chrome

1. Clone or download this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the folder you cloned/downloaded (the one containing `manifest.json`).
5. Open an ordinary `http` or `https` page. If PageDNA has no access yet, use **GRANT SITE ACCESS** in the popup and reload the page.
6. The popup shows **NOT MONITORED**; choose **CREATE BASELINE**.
7. Reload the page to verify the **TRUSTED** state.
8. Use **INVESTIGATE**, **TRUST THIS CHANGE**, or **IGNORE ONCE** when evidence appears.

## Test fixture lab

The fixture lab is a local file, so it needs no server:

1. On PageDNA's card in `chrome://extensions`, click **Details** and enable **Allow access to file URLs**.
2. Open `test-harness/example-site.html` directly in Chrome (drag it into a Chrome window, or `Ctrl+O`).
3. Create a baseline for it, then click one fixture control at a time — each one flips a setting and reloads automatically. Click **Reset all fixtures** to return to the clean baseline between tests.

| Fixture | Expected result |
|---|---|
| Toggle harmless styling | Still TRUSTED — no alert |
| Add new iframe | CHANGES DETECTED, medium risk |
| Add new script | CHANGES DETECTED, medium risk |
| Change login destination | CHANGES DETECTED, high/critical risk |

## Test code

Run `npm test` or `node tests/run-tests.js`. The suite covers URL canonicalization, script/frame/form diffs, sensitive-flow scoring, score bounding, and risk levels.

## Architecture

```
manifest.json
src/
  background/   service-worker.js, baseline-manager.js, diff-engine.js, notifications.js, event-store.js
  content/      content.js, dom-analyzer.js, form-analyzer.js, frame-analyzer.js, canonicalizer.js
  popup/        popup.html, popup.js, popup.css
  options/      options.html, options.js, options.css
  shared/       constants.js, schema.js, messages.js
test-harness/   example-site.html, README.md
tests/          run-tests.js, fixtures.js
```

## Privacy and trust model

PageDNA stores semantic structure and origins only — no passwords, cookies, tokens, or form values. Baselines are versioned; trusting a change creates a new baseline version, and ignoring a change suppresses it for a limited period without rewriting the baseline.
